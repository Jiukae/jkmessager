## 구성

**3D (three.js, 헤드리스 Chromium에서 프레임 단위 렌더)** — `scene/`
- 패스 3단 굴절 파이프라인: A(불투명 소품 + 얼음) → 피사계 심도 → B(액체, A를 굴절) → C(유리 겉면, A+B를 굴절) → 블룸·필름 그레이딩. 그래서 유리 너머 배경은 흐리고 유리 자체는 선명합니다.
- 액체: 비어-람베르트 흡수(가장자리는 호박색, 가운데는 진한 갈색), 에스프레소가 위에 뜨는 농도장과 저을 때의 소용돌이, 수면 리플, 크레마.
- 얼음: cannon-es 강체 시뮬레이션(낙하·부력·스트로 교반), 구름 낀 얼음 코어를 레이 마칭으로 표현.
- 유리 표면 결로(물방울 노멀맵), HDRI + 소프트박스 반사, 원목 테이블·원두는 절차적 텍스처.

**목소리** — `audio/tts.py`
- 오프라인 한국어 VITS 음성(sherpa-onnx, KSS). 문장마다 여러 테이크를 만든 뒤 한국어 음성 인식(SenseVoice)으로 받아쓰기가 가장 정확한 테이크를 자동 선택합니다.

**효과음 · 음악 · 믹스** — `audio/mix.py`
- 얼음 소리는 물리 시뮬레이션의 실제 충돌 이벤트마다 배치합니다. 세기는 충돌 속도를, 음높이와 울림은 그 순간 컵에 찬 양을 따릅니다.
- 물/샷 붓는 소리: 미나르트 기포 합성 + 컵이 찰수록 음이 올라가는 공기 기둥 공명. 에스프레소 펌프·솔레노이드·드립, 얼음 갈라지는 소리, 저을 때 소리, 장면 전환 휘시, UI 팝, 카페 앰비언스.
- 절차적 로파이 BGM(86BPM), 내레이션에 맞춰 덕킹, 최종 −14 LUFS.

## 다시 만들기

```bash
./build.sh             # 전체 1080x1920 렌더 (4코어 CPU 소프트웨어 WebGL 기준 약 45–90분)

```
