## 구성

**3D (three.js, 헤드리스 Chromium에서 프레임 단위 렌더)** — `scene/`
- 패스 3단 굴절 파이프라인: A(불투명 소품 + 얼음) → 피사계 심도 → B(액체, A를 굴절) → C(유리 겉면, A+B를 굴절) → 블룸·필름 그레이딩. 그래서 유리 너머 배경은 흐리고 유리 자체는 선명합니다.
- 액체: 비어-람베르트 흡수(가장자리는 호박색, 가운데는 진한 갈색), 에스프레소가 위에 뜨는 농도장과 저을 때의 소용돌이, 수면 리플, 크레마.
- 얼음: cannon-es 강체 시뮬레이션(낙하·부력·스트로 교반), 구름 낀 얼음 코어를 레이 마칭으로 표현.
- 유리 표면 결로(물방울 노멀맵), HDRI + 소프트박스 반사, 원목 테이블·원두는 절차적 텍스처.

**목소리** — `audio/tts.py`
- 상업용: Google Cloud Text-to-Speech, 한국어 남성 Chirp 3 HD 음성(기본 `ko-KR-Chirp3-HD-Achird`). 환경 변수 `GOOGLE_TTS_API_KEY`가 있으면 자동으로 사용합니다. `TTS_VOICE`로 다른 음성을 고를 수 있습니다(예: `ko-KR-Chirp3-HD-Puck`, `ko-KR-Chirp3-HD-Charon`, `ko-KR-Neural2-C`).
- 키가 없으면 오프라인 한국어 VITS 음성(sherpa-onnx, KSS, 여성)을 씁니다. 문장마다 여러 테이크를 만든 뒤 한국어 음성 인식(SenseVoice)이 가장 정확하게 받아쓴 테이크를 고릅니다.
- `TTS_FIT=1`: 이미 렌더링한 영상의 자막 타이밍에 맞춰 각 문장을 음높이 변화 없이 늘이거나 줄입니다(rubberband).

**효과음 · 음악 · 믹스** — `audio/mix.py`
- 얼음 소리는 물리 시뮬레이션의 실제 충돌 이벤트마다 배치합니다. 세기는 충돌 속도를, 음높이와 울림은 그 순간 컵에 찬 양을 따릅니다.
- 충돌음은 모달 합성으로 만듭니다. 접촉 시간(세기)에 따라 밝기가 바뀌고, 유리 공진은 살짝 어긋난 쌍으로 울려 실제 유리컵 같은 잔향이 납니다. 첫 얼음은 컵 바닥에 "툭" 떨어지는 저음이 더해집니다.
- 물/샷 붓는 소리: 물줄기 난류 + 미나르트 기포 + 컵이 찰수록 음이 올라가는 공기 기둥 공명(기본음·3배음), 첫 닿는 물보라와 마지막 물방울. 뜨거운 샷이 닿으면 얼음이 "타닥" 갈라집니다.
- 에스프레소 머신: 스위치 딸깍, 솔레노이드, 50Hz 진동 펌프(압력이 오르며 무거워짐), 샷 잔에 떨어지는 소리(잔이 찰수록 음이 오름), 추출 후 압력 배출 "칙" 소리, 보일러 험.
- 젓기: 한 바퀴에 두 번 출렁이는 소용돌이 소리 + 얼음 달그락. 장면 전환 휘시(서브 저음 포함), 물방울 UI 팝, 오프라인 음성으로 만든 웅성거림이 들어간 카페 앰비언스, 반사음이 있는 작은 카페 잔향.
- 절차적 로파이 BGM(86BPM), 내레이션에 맞춰 덕킹, 최종 −14 LUFS.

## 다시 만들기

```bash
./build.sh               # 전체 1080x1920 렌더 (4코어 CPU 소프트웨어 WebGL 기준 약 65분)
PREVIEW=1 ./build.sh     # 540x960 · 10fps 미리보기 (약 7분)
AUDIO_ONLY=1 ./build.sh  # 화면은 그대로 두고 목소리·효과음만 다시 만들어 교체 (약 1분)
```

남성 상업용 내레이션으로 바꾸려면 환경 설정에 `GOOGLE_TTS_API_KEY`(Text-to-Speech API가 켜진 Google Cloud API 키)를 추가하고 `AUDIO_ONLY=1 ./build.sh`를 실행하세요.

필요: Node 18+, Python 3.10+, ffmpeg, Playwright Chromium.
